# NPC models

Original low-poly figures for Escape Berghain. `node scripts/build-npc-models.mjs` rewrites `npc_*.glb`.

The game loads each file through `placeModel()`. A missing or broken file stays a grey box of the same size. Nothing crashes on a 404.

## Where the look comes from

The silhouettes take a loose cue from early-2000s open-world street crowds: a young woman in street clothes, a loud shirt, bouncers, glam, leather. They are refit for this club. Mostly black, harnesses, a few people who missed the dress code, and equine guests (horse, unicorn, donkey) in the same clothes.

No meshes, textures, or names from Grand Theft Auto or any other game are in this folder. A downloadable "white female young street" model online is a ripped game file under a personal-use-only licence. It was not downloaded and is not included. `npc_tourists.glb` is an original stand-in for that look: light skin, long hair, jeans, a pale jacket.
