# Fonts

All SIL Open Font License 1.1, from the official Google Fonts repository (github.com/google/fonts). Licence texts sit next to each font.

| File | Used for |
|---|---|
| BigShouldersDisplay-wght.ttf | Titles, end cards, big numbers |
| SairaStencilOne-Regular.ttf | Zone signs, exit, closing time, stamps |
| SpaceMono-Regular.ttf, SpaceMono-Bold.ttf | Labels, label-maker tape captions |
| FragmentMono-Regular.ttf | Dialogue, HUD, objectives |

Self-hosted so the live demo never depends on a font server.
