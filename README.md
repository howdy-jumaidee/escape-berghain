# Escape Berghain

You took too much. You are a horse. Get home before your memory slips away.

**Play it:** https://escape-berghain.vercel.app (production, from `main`)

Team Five, 24 hour game hackathon. Dee (code), Emma (3D), Robin (strategy).

## Run it

```
npm install
npm run dev
```

WASD to walk. Space to grab and talk. Q to look at yourself. E to stomp on the beat. M to mute.

## Start here

- `docs/TEAM.md` setup for Dee (Zed), Emma (Cursor) and Robin (Lovable)
- `AGENTS.md` how we work: branches, CI, reviews. Every agent reads this
- `ROADMAP.md` phases and gates
- `docs/PLAN.md` the game, story, NPCs, assets, timeline
- `src/contracts.ts` shared state and events

## Stack

Vite, TypeScript, Three.js, postprocessing, Rapier. Hosted on Vercel.
